# GalaxyBot-Challenge

## Getting Started

### 1. Install Dependencies
```bash
bun install
```

### 2. Create .env File
Create a `.env` file in the root directory of your project and add the following environment variables:

```
BOT_TOKEN=your_discord_bot_token
```

### 3. Start the Bot
Start the Bot with `bun run dev` or `bun run dev:win` if you are on Windows.

## Requirements
- Bun
- An Discord Application created on the [Discord Developer Portal](https://discord.com/developers/applications)
